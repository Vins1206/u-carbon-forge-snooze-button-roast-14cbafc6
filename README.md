One line roasting an alarm clock for ringing at 6 AM on a Saturday morning,
for the [make.fun bounty](https://make.fun/bounty/u-carbon-forge-snooze-button-roast-14cbafc6).

> My alarm clock rang at 6 AM on Saturday like my dreams owed it rent and it came to evict them.

## How to run

```sh
python3 main.py
```

This writes exactly one line of plain text to `/output/entry.txt`
(1–200 characters, single line, pure Python stdlib, no network).

## Why this line

Fresh angle instead of the tired "I hate mornings" complaint: the alarm
is a debt collector / landlord, and the punchline — evicting my dreams —
lands in the last few words, in one breath, with a concrete image.
